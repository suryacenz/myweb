關於我與學歷背景

你好！我是鄭德忠（De-Zhong Zheng），目前就讀於位於桃園市龜山區的龍華科技大學（Lunghwa University of Science and Technology）。

在學期間，我積極將課堂上的理論知識轉化為實際可運作的系統與網頁專案。從基礎演算法邏輯、前端互動介面設計到後端資料處理，我都保持高度好奇心，享受將構想一步步實作出來的成就感。

除了日常課程與實務專題外，我也習慣利用 Git 與 GitHub 管理程式碼版本，並持續自學現代化開發工具，期許自己成為兼具技術深度與團隊溝通力的工程人才。
